# 🏠 서울 월세 가격 비교 대시보드 (1~4인가구)

서울특별시 부동산 전월세 실거래가 데이터(2021~2025년, 정제 월세 약 147만 건)를 바탕으로 **1인가구·2인가구·3인가구·4인가구**별 서울 25개 자치구 월세 가격을 **서울 지도 위 히트맵**과 인터랙티브 차트로 비교하는 Streamlit 웹 대시보드입니다.

## 주요 기능
- **멀티페이지 구성**: `종합 비교` / `1인가구 (~33㎡)` / `2인가구 (33~50㎡)` / `3인가구 (50~75㎡)` / `4인가구 (75㎡ 초과)` / `데이터 출처 및 기준`
- **서울 지도 위 월세 히트맵**: 자치구 경계 히트맵(Choropleth)과 연속 열지도 히트맵(Density Heatmap) 전환 지원
- **실시간 필터 연동**: 연도 범위(2021~2025), 건물 용도(아파트·오피스텔·연립다세대·단독다가구), 가격 지표(명목 월세·환산월세·평당월세·보증금), 통계 기준(중앙값·평균), 관심 자치구 강조
- **심층 분석 차트**: 25개 자치구 순위 막대 차트, 연도/월별 시계열 추이, 건물용도별 가격·비중 비교, 법정동별 TOP 12 순위, 보증금-월세 반전세 산점도, CSV 다운로드

## 로컬 실행 방법
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud 배포 방법
1. 이 폴더의 모든 파일(`app.py`, `requirements.txt`, `.streamlit/`, `data/`, `utils/`, `views/`)을 GitHub 공개(Public) 저장소에 업로드합니다.
2. [share.streamlit.io](https://share.streamlit.io)에서 GitHub 저장소를 연결하고 Main file path를 `app.py`로 지정해 배포합니다.
